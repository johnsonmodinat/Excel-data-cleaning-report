# Excel Data Cleaning and Preparation Project 📊

# About the Project
This is one of my data analytics projects, where I used Microsoft Excel to clean and prepare a dataset containing 1,200 order records. I wanted to get more hands on experience with data cleaning and understand how to identify and handle data quality issues before moving on to analysis. Working on this project helped me put some of my Excel skills into practice and appreciate the importance of making careful decisions when working with data.

# Tools Used
 Microsoft Excel

# What I Worked On
* Inspected the dataset to identify missing values and other data quality issues.
* Found 309 blank entries in the 'coupon code' column and replaced them with "No coupon."
* Checked for duplicate records and found no exact duplicate rows.
* Used Excel formulas to check whether the recorded 'Total Price' values matched the quantity multiplied by the unit price.
* Reviewed the data formats and text consistency.
* Created a cleaning log to document the issues I found and the actions I took.

# A Few Things I Learned
One of the things that stood out to me was that cleaning data isn't just about fixing what looks wrong. It's also about understanding the data and being careful not to make assumptions without acknowledging them.
For example, I replaced the blank coupon entries with "No coupon," although the original dataset didn't confirm whether those blanks meant that no coupon was used. I documented this as an assumption rather than treating it as a confirmed fact.
I also learned the importance of validating existing values instead of automatically changing them.
